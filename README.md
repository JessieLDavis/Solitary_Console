# Solitary_Console

## Summary
This is a test file I wrote while learning Python. It allows you to play Klondike Solitare in the console. I plan to expand on this code in later versions.

## How to run:

1. **Direct Method**
In the terminal run:
> cd Solitary_Console
> python main.py

2. **Virtual Enviroment Method**
In the terminal:
*Navigate to the proper folder*
> cd Solitary_Console

*Make .venv*
> python -m venv .venv

*Start venv*
Mac:
> source .venv/bin/activate

Windows:
> .venv/Scripts/activate

*Run program*
> python main.py

Enjoy!
